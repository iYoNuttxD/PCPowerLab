# Revisão técnica do catálogo e preservação de configurações

Observação comercial: 08/10/2026.

Foram retirados da seleção nova 20 modelos sem cotação utilizável e adicionados 19 modelos distintos. As duas referências Samsung NVMe de 1 TB apontam para o mesmo XPG S70 BLADE, sem duplicar o SKU. O catálogo passa a 97 componentes ativos; os 20 registros anteriores continuam disponíveis para resolver configurações salvas.

Todos os 97 componentes ativos têm preço de referência e fotografia com procedência registrada. Isso não significa estoque atual garantido: 21 referências registraram disponibilidade na consulta e 76 têm estoque não confirmado. As 19 novas referências têm evidência de disponibilidade na observação. Nenhuma é apresentada como API de preços ao vivo.

## Diferenças que exigem atenção

- Mantém AM5, B650, DDR5 e formato mATX. O modelo Gigabyte tem limites próprios de memória, slots e conectores; confira BIOS e QVL.
- Placa-mãe não recebe ganho de FPS ou pontuação de processamento por esta troca.
- Especificações: [fonte do fabricante](https://www.gigabyte.com/Motherboard/B650M-D3HP-rev-1x/sp)

### Montech Air 903 Base → Cooler Master Elite 502 White

- O limite do cooler passa de 180 para 170 mm. O limite conservador de GPU é 360 mm; até 410 mm somente nas condições descritas pelo fabricante.
- Três fans de 120 mm incluídos; mudam posições, capacidade de ventoinhas e limites de radiador. A variante é branca.
- Especificações: [fonte do fabricante](https://www.coolermaster.com/en-us/products/elite-502.html)

### Crucial 32GB DDR4-3200 UDIMM → Kingston ValueRAM 32GB (1x32GB) DDR4-3200 CL22

- Mantém um módulo de 32 GB DDR4-3200 JEDEC. Confirme suporte a módulos de 32 GB nesta placa-mãe.

## Identidade, pontuação e compatibilidade

O armazenamento de builds desta aplicação continua em memória. Esta revisão preserva a resolução dos IDs históricos; não adiciona persistência durável entre reinicializações. Nos testes, importar significa validar a seleção exportada e salvá-la como nova build. Não há endpoint HTTP para restaurar IDs, timestamps, versões ou compartilhamentos históricos de forma idêntica.

- Nenhum ID antigo é renomeado para outro produto. Cada modelo anterior mantém nome, SKU, especificações, imagem, preço histórico ausente e parâmetros históricos. `replacementId` é uma sugestão; não altera o componente escolhido.
- Listas de seleção, custo-benefício e recomendações usam somente modelos ativos. A consulta com `includeLegacy=true` permite hidratar os registros anteriores em telas, versões, relatórios e compartilhamentos. Registros administrativos desativados comuns continuam fora dessa consulta.
- Ao escolher uma alternativa, preço, orçamento, consumo, compatibilidade, índices, comparação e proposta de upgrade são recalculados. Salvar, importar ou abrir uma configuração antiga não aplica a troca.
- RAM usa o modelo interno existente: `min(92, 50 + capacidadeGb / 2 + (MT/s - 3200) / 200)`. Armazenamento usa `min(92, 50 + leituraMbS / 200)`. Os novos valores usam entradas verificadas dos novos produtos. CL, controlador, resistência a gravações e desempenho sustentado não são medidos por essa fórmula.
- Esses índices são estimativas internas e não benchmarks medidos. Placas-mãe, gabinetes, coolers e ventoinhas novos não ganham pontuação de processamento ou bônus de FPS.
- Foram adicionados limites oficiais de slots de RAM, capacidade e comprimentos M.2 para seis placas-mãe existentes e a nova B650M D3HP. Identidades genéricas não são convertidas silenciosamente em outra variante: limites ausentes continuam não verificados.
- As novas combinações verificam quantidade de módulos, capacidade máxima e comprimento M.2 quando esses modelos são envolvidos. XMP/EXPO, versão de BIOS, QVL, compartilhamento de pistas e encaixes detalhados ainda exigem consulta do hardware específico.
- O kit Cooler Master tem três fans. Preço é por pacote; consumo cadastrado é 3,45 W por fan, totalizando 10,35 W por pacote antes do consumo não especificado da controladora. Quantidades de pacotes multiplicam cada base apenas uma vez.
- O preset de edição de vídeo passa a Ryzen 7 7700 e B650 Gaming X AX para utilizar limites verificáveis, com análise e custos recalculados. As configurações Intel já salvas não são alteradas.

## Reproduzir as verificações

- `npm test`
- `npm run lint`
- `npm run audit:images`
- `cd frontend && npm run lint && npm run build`

O teste de referências preserva fatos comerciais congelados, separados dos cálculos de runtime. Os testes de substituição incluem identidade histórica, persistência, exportação/importação, versões, compartilhamento, relatórios, recomendações, incompatibilidades, dados ausentes, quantidades e consumo.

## Resultado técnico desta revisão

- 642 testes Node aprovados, zero falhas; essa contagem já inclui testes unitários frontend encontrados pelo executor Node
- 14 verificadores de renderização estática e handlers aprovados
- Lint backend/frontend e build de produção aprovados
- Auditoria de imagens: 97/97 componentes ativos, zero fallback, arquivos órfãos ou duplicações suspeitas
- Presets não verificados, incompatíveis ou inválidos são isolados na listagem com diagnóstico por ID; um item não interrompe os demais
- Cards prontos recalculam o total pelos preços atuais do catálogo, não exibem as faixas antigas como promessa e preservam o orçamento já informado pelo usuário
- Regressões de navegador adicionadas; execução visual desta revisão ainda pendente. Verificações estáticas não comprovam geometria, foco ou navegação real
